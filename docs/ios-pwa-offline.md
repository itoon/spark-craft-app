# iPhone / iPad — ติดตั้งแอปจากลิงก์ Share และใช้ออฟไลน์

iPhone ติดตั้ง APK ไม่ได้ เลยใช้วิธี **เว็บแอป (PWA)** แทน: นักเรียนเปิดลิงก์ Share ใน Safari → เพิ่มไปยังหน้าจอโฮม → ได้ icon แอปของตัวเอง เปิดเต็มจอ และใช้ได้แม้ไม่มีเน็ต

ทำงานใน Wi‑Fi ห้องเรียนวงเดียวกัน ไม่ต้องมีอินเทอร์เน็ต

## ครู: เปิดเซิร์ฟเวอร์ห้องเรียน
```bash
bun run serve:lan
```
- ครั้งแรกจะ build CodeCraft (1–2 นาที) และสร้าง **ใบรับรองห้องเรียน** ไว้ใน `.certs/`
- จะขึ้นที่อยู่ เช่น `https://192.168.1.184:3443/editor` — เปิด editor จากที่อยู่นี้แล้วกด **Share**
- แก้โค้ด CodeCraft เองแล้ว ให้รัน `bun run serve:lan --build`
- ใช้คู่กับ `bun run dev` ได้ (คนละพอร์ต: dev = 3000, ห้องเรียน = 3443)

> ทำไมไม่ใช้ `bun run dev`: ออฟไลน์ต้องเก็บไฟล์ของแอปไว้ในเครื่อง ซึ่งทำได้กับไฟล์ที่ build แล้วเท่านั้น
> `bun run dev:https` ใช้ใบรับรองเดียวกัน — กล้อง/GPS บน iPhone ใช้ได้ แต่ยังไม่ออฟไลน์

## มือถือแต่ละเครื่อง: ติดตั้งใบรับรอง (ครั้งเดียว)
เปิด `https://<ip คอมครู>:3443/cert` ใน Safari (ถ้าขึ้นเตือน กด “แสดงรายละเอียด → เยี่ยมชมเว็บไซต์นี้”) แล้วทำตามหน้าจอ:
1. ดาวน์โหลดใบรับรอง → อนุญาต
2. การตั้งค่า → **ดาวน์โหลดโปรไฟล์แล้ว** → ติดตั้ง
3. การตั้งค่า → ทั่วไป → เกี่ยวกับ → **การตั้งค่าความเชื่อถือของใบรับรอง** → เปิด *CodeCraft Classroom CA*

IP ของคอมครูเปลี่ยนก็ไม่ต้องติดตั้งใหม่ — `serve:lan` ออกใบใหม่ให้เองจากใบรับรองห้องเรียนเดิม (อย่าลบ `.certs/ca.pem` / `ca-key.pem` ไม่งั้นทุกเครื่องต้องติดตั้งใหม่)

## นักเรียน: ติดตั้งแอป
1. สแกน QR จากปุ่ม Share → เปิดใน **Safari**
2. แตะ **แชร์** → **เพิ่มไปยังหน้าจอโฮม** (หน้าแอปจะขึ้นคำแนะนำนี้ให้เอง)
3. เปิดจาก icon บนหน้าจอโฮม **ครั้งแรกตอนยังต่อ Wi‑Fi ห้องเรียน** จนขึ้น “พร้อมใช้ออฟไลน์แล้ว”
4. หลังจากนั้นเปิดได้แม้ปิดคอมครูหรือออกนอกห้องเรียน

ครูแก้แอปแล้วกด Share ซ้ำ (ลิงก์เดิม) — นักเรียนเปิดแอปตอนต่อ Wi‑Fi ห้องเรียนก็ได้เวอร์ชันใหม่

> iPhone เก็บข้อมูลของแอปบนหน้าจอโฮมแยกจาก Safari จึงต้องเปิดจาก icon ตอนออนไลน์ 1 ครั้ง (เปิดใน Safari อย่างเดียวไม่พอ)

## อะไรใช้ได้บน iPhone

| ความสามารถ | iPhone | หมายเหตุ |
|---|---|---|
| element ทั่วไป, Sound, `phone.speak`, storage | ✅ ออฟไลน์ได้ | |
| กล้อง (Camera) | ✅ | ถามสิทธิ์ตอนเปิดกล้อง (บางครั้งถามใหม่ทุกครั้งที่เปิดแอป) |
| GPS (`location.*`) | ✅ | |
| เขย่า/เอียง (`motion.*`) | ✅ | ต้องแตะหน้าจอก่อน แล้วกดอนุญาต |
| แผนที่ (Map) | ⚠️ | ต้องมีอินเทอร์เน็ตตอนดูแผนที่ |
| `phone.vibrate()` | ❌ | Safari ไม่มีการสั่น |
| Bluetooth (`ble.*`) | ❌ | iPhone ไม่มี Web Bluetooth |

## ทำงานยังไง (สำหรับคนแก้โค้ด)
- `scripts/lan-cert.mjs` — CA ห้องเรียน + ใบรับรองเซิร์ฟเวอร์ตาม IP ปัจจุบัน (openssl ของ macOS, ไม่แตะ keychain ของเครื่อง)
- `scripts/serve-lan.mjs` — build ลง `.output-lan` แล้วรัน Nitro แบบ HTTPS (`NITRO_SSL_CERT`)
- `server/routes/sw.js.get.ts` + `server/utils/serviceWorker.ts` — service worker: เก็บทุกไฟล์ใน `/_nuxt` ตอนติดตั้ง, หน้าเว็บกับข้อมูลแอปดึงจากเน็ตก่อนแล้วค่อยใช้ของในเครื่อง
- `server/api/pwa/[id]/` — manifest + icon ของแต่ละแอป (icon มาจาก “แอปของฉัน” ตอนกด Share)
- `app/composables/usePwaOffline.ts`, `app/components/export/PwaInstallHint.vue` — ลงทะเบียน service worker และคำแนะนำบนหน้า `/pwa/<id>`
- icon ของ Nuxt UI ถูก bundle มากับแอป (`@iconify-json/lucide`) ไม่ต้องโหลดจากอินเทอร์เน็ต
