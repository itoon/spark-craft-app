# CodeCraft Ionic App

Generated from CodeCraft as an Ionic Vue + Capacitor starter project.

## Run locally

1. npm install
2. npm run dev

## Build the web app

1. npm run build

## Open Android Studio or Xcode

1. npm run cap:sync
2. npm run cap:android
3. npm run cap:ios

This export keeps your CodeCraft pages, element tree, and page code in:

- src/data/codecraft-app.ts
- src/runtime/codecraft-runtime.ts
- src/views/CodeCraftPage.vue
